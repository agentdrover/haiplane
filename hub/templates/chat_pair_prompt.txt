Тебя подключают к хабу задач Haiplane. Ниже одноразовый код. Он обменивается на короткую сессию, которой хватает только на постановку и уточнение задач.

Хаб: {{ base_url }}
Код: {{ code }}

Шаги:
1. Обменяй код на сессию. Код живёт около 5 минут и работает один раз, поэтому сделай это первым шагом:
   curl -sS -X POST {{ base_url }}/api/auth/chat-pair/redeem -H 'Content-Type: application/json' -d '{"code":"{{ code }}"}'
   В ответе поле token. Дальше передавай его в заголовке Authorization: Bearer <token>.
2. Проверь сессию: GET {{ base_url }}/api/whoami. Должно быть auth_source=chat_pair.
3. Поставь задачу: POST {{ base_url }}/api/tasks с JSON {"title": "...", "description": "..."}. Уточни её через refine, если оператор дополнит условия.
4. Верни оператору номер созданной задачи и её заголовок.

Правила:
- Токен не печатай нигде: ни в чате, ни в обновлениях задач, ни в описании PR. Других токенов у оператора не проси.
- Не передавай run_immediately и не ставь auto_review=false: запрос будет отклонён с 422 chat_pair_run_forbidden. Запуск исполнения делает оператор из хаба.
- Всё, кроме постановки и уточнения задач, закрыто. Ответ 403 chat_pair_gate_forbidden означает границу канала, а не ошибку: не обходи её, скажи оператору.
- Повторный обмен того же кода даёт 401 chat_pair_invalid. Не повторяй его: попроси оператора выдать новый код.
