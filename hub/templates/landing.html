{{ product_name }} Hub

Оркестратор задач для разработки с AI-агентами. Отвечает на вопрос, который агент о себе не отвечает: доехал ли код до прода.

Заявлено — не значит доставлено

Агент рапортует «готово», а ветка не смержена, PR открыт, прод живёт прошлой версией. Хаб не верит отчёту на слово: он ведёт задачу через гейты и сверяет заявленное с фактом по git.

  • Definition of Ready как контракт — критерии приёмки называют тест или команду проверки, иначе задача не уходит в работу.
  • Ревью-цикл перед завершением — вердикт привязан к текущей сдаче: пересдал работу, прежний апрув сгорел.
  • Учёт доставки до SHA — хаб помнит мерж-коммит задачи и коммит выката и отвечает, что из завершённого реально работает.
  • MCP-интерфейс для агентов — тот же контур доступен Cursor, Claude Code и любому MCP-клиенту.

Попробовать

git clone https://github.com/agentdrover/haiplane.git
cd haiplane
docker compose up
