{# #1812: раскрытие блоков карточки. Состояние каждого
с id хранится в sessionStorage по id блока и возвращается после каждой замены .main HTMX (обновление раз в 15 с): ручное раскрытие и закрытие не сбрасываются. Ширина >=1101px задаёт только начальное значение «Подробностей»: если записанного состояния нет. «К действию» не отменяет переход - фрагмент пишется в адрес, а блок с целью раскрывается. Хранилище может быть недоступно (приватный режим): всё в try/catch, страница работает без него.
