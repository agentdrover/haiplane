{# #1812: раскрытие блоков карточки. Состояние каждого
с id хранится в sessionStorage по id блока и возвращается после каждой замены .main HTMX (обновление раз в 15 с): ручное раскрытие и закрытие не сбрасываются. - Перед заменой (htmx:beforeSwap) состояние снимается с живых узлов: запись из события toggle асинхронна и могла бы не успеть. - Ширина >=1101px - только начальное значение «Подробностей»: оно записывается при первой загрузке и дальше не перечитывается. - Ответ на действие (details пришёл с open) раскрывает блок при загрузке страницы; при последующих заменах побеждает записанное состояние. - Фрагмент адреса раскрывает блок с целью при загрузке, смене фрагмента и клике «К действию» (переход не отменяется), но не при замене .main. Хранилище может быть недоступно (приватный режим): всё в try/catch. Скрипт приходит и с каждой заменой .main, поэтому обработчики ставятся один раз (флаг window.hubC2); каждый запуск лишь восстанавливает состояние. #}
